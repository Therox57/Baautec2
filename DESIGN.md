# TEC website design direction

User preference, 2026-10-07: work from the original full portal preview (2596327), not the stripped-down version (309ac54). A modern, visually complete university portal is wanted; neither generic AI marketing templates nor a bare text page.

## Rules for future UI changes
- Keep the TEC identity: official supplied logo, navy, restrained warm accents. Avoid unrelated stock visuals or invented university photographs.
- Establish typography, palette, spacing, component sizes and page hierarchy before editing. Use a coherent spacing scale and mobile layouts.
- Keep useful visual structure: branded introduction, event dates, club identities, clear navigation and visible registration. Do not remove richness merely to avoid AI slop.
- Write factual Azerbaijani labels. Avoid repetitive slogans, grand claims, fake statistics, unnecessary badges, gradients and identical card grids for every section.
- Treat the supplied reference as design guidance; do not copy unrelated branding or install tools automatically.
- Verify build, navigation, filter behavior and accessibility. Inspect desktop and mobile screenshots through an available supported browser. If browser access is unavailable, say so; compilation does not prove visual quality.
- Preserve confirmed content. Plans are plans; missing times, rooms and registration links must remain visibly unconfirmed.
- Publish iterations to the preview branch until the user requests main.
